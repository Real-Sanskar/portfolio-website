# My Portfolio Website
	
This is my personal portfolio site that I made using HTML and CSS.  
I wanted a place to show my skills, practice projects, and also have something I can share with recruiters later.

---

## What’s inside
- A hero section with my name and intro
- About me section with a short description
- Skills section (C++, DSA, HTML, CSS, SQL, GitHub, and currently learning JavaScript)
- Projects section where I’ll keep adding my work (right now it has my DSA repo and CSS practice components)
- Contact form and links to my email, LinkedIn, and GitHub

---

## Why I built this
I’ve been learning frontend step by step. After finishing HTML and CSS basics, I decided to make this portfolio as a practical project.  
It’s simple, but it helped me revise concepts like Flexbox, Grid, responsive design, and animations.

---

## Tech Used
- HTML5
- CSS3 (Flexbox, Grid, Animations, Transitions)
- Git & GitHub
